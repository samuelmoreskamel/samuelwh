# Liteway Store Catalog

مشروع Android جاهز للرفع على GitHub.

- البحث بكود الصنف بدون حساسية لحالة الحروف.
- يعرض الصورة المرجعية من صفحة المصدر، الاسم العربي والإنجليزي، والمواصفات المتاحة.
- عدد الأكواد المدرجة: 285 كودًا فريدًا من acc.pdf.

## البناء على GitHub
1. أنشئ Repository جديدًا.
2. فك ZIP وارفع **المحتويات** إلى جذر الـRepository، بما في ذلك مجلد `.github`.
3. افتح Actions > Build Android APK > Run workflow.
4. بعد نجاح التشغيل حمّل Artifact باسم `LitewayStoreCatalog-debug-apk`.

## ملاحظة الصور
النسخة الأولى تستخدم صورة مرجعية لصفحة المصدر لضمان عدم ربط صورة خاطئة بكود. يمكن لاحقًا استبدالها بصورة المنتج المنفردة لكل كود داخل `app/src/main/assets/images/` مع الحفاظ على نفس التطبيق.
